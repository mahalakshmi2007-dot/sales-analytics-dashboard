# Sales Performance Excel Dashboard

## 📌 Project Overview

This project analyzes sales data using Microsoft Excel to understand
sales performance, product performance, regional performance and profit trends.

## 🎯 Objective

The objective is to transform raw sales data into meaningful business
insights using Excel data cleaning, formulas, Pivot Tables and charts.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Visualization

## 📊 Analysis

The project will analyze:

- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by Region
- Monthly Sales
- Top Products
- Profit Performance
